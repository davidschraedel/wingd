# Wingd - Online Dating Prototype
2025

A referral-based dating app that brings word-of-mouth matchmaking into modern online dating. Instead of relying on algorithmic feeds and endless swiping, Wingd empowers friends to act as wingmen or wingwomen, facilitating warm introductions, trusted connections, and peer-driven dating within real-world social circles.

---

## Features

- **Circles & Trusted Connections:** Connect with friends, acquaintances, and peers to build your matchmaking network.
- **Peer Introductions:** Introduce two people in your circle with customized notes and context.
- **Review & Accept:** Browse incoming introductions, view detailed profiles and mutual interests, and decide whether to connect.
- **Direct Messaging:** Chat seamlessly with introduced matches once an introduction is accepted.
- **User Profiles:** Highlight personal interests, creative passions, and verified social circles.

---

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm`

### Installation

Clone the repository and install dependencies:

```bash
cd wingd
npm install
```

### Development

Start the local Vite development server:

```bash
npm run dev
```

Open your browser to the URL indicated in the terminal (typically `http://localhost:5173`).

### Production Build

Create an optimized production bundle:

```bash
npm run build
```
